01

Чем занимаюсь

Встраиваемые системы

ESP32 и STM32, шаговые приводы, датчики, дисплеи. Прошивки на C/C++ для устройств, которые работают руками, а не в демо.

Telegram-боты

aiogram и Telethon, Mini Apps, сценарии с очередями и расписанием. Развёртывание на своём сервере, логи, автоперезапуск.

Инфраструктура

Debian, systemd, Docker, nginx, оркестрация деплоя и резервные копии. Чтобы сервисы жили, а не «работали у меня локально».

Данные

Парсеры каталогов и маркетплейсов, обход пагинации и защит, нормализация в базу, выгрузки и API поверх собранного.

Проекты

Mini App для косметики: каталог, карточки товаров, связка с ботом. Статика на GitHub Pages, данные из бота.

Embeddedостановлен

Станок опрессовки трубок

Собственная прошивка на C++ и управление двумя шаговыми приводами NEMA24 через MKS Monster8. Ручной и автоматический циклы, концевики, аварийный останов. Задача закрыта на стороне заказчика до пуска.

PWAв работе

Sweet Calc

Офлайн-калькулятор для домашней кондитерской: себестоимость, техкарты, пропорции замеса, КБЖУ. Данные остаются на устройстве, работает без интернета.

Embeddedзаморожен

Автомат для узла PR Knot

Кинематика узла для плетёного шнура на ESP32-S3 и TMC2209. Остановился на расчёте траектории вращения.

Androidв работе

Лёгкий клиент для музыки

Kotlin и Compose, Media3, FLAC без потерь, корректные переходы между треками. Собственная сборка вместо тяжёлого клиента.
