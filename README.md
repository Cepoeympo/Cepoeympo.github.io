# cepoeympo.github.io

Личная страница: **https://cepoeympo.github.io/**

Профиль инженера-разработчика: чем занимаюсь, проекты, опыт, сертификаты,
небольшая игра и контакты. Одна страница, чистый HTML/CSS/JS — без сборки,
зависимостей и фреймворков.

## Что где лежит

```
index.html     вся страница: разметка, стили, логика игры
i18n.js        словарь интерфейса на семь языков
404.html       страница для несуществующих адресов
images/        портрет, превью и оригиналы сертификатов
sounds/        три звука пасхалки
.nojekyll      отключает Jekyll — файлы отдаются как есть
```

## Языки

Русский, английский, немецкий, французский, испанский, китайский, японский.

Язык определяется сам: сначала сохранённый выбор, потом `navigator.languages`,
фолбэк — английский. Выбор запоминается в `localStorage`.
Переключатель — в правом верхнем углу.

Тексты лежат в `i18n.js`, ключи совпадают с атрибутами `data-i18n`
и `data-i18n-html` в `index.html`. Чтобы поправить формулировку, достаточно
изменить строку в нужном языковом блоке: разметку трогать не нужно.

## Как править

Сборки нет. Правится `index.html`, коммит в `master` — Pages пересобирается
сам, новая версия появляется через одну-две минуты.

Пасхалка — пять, десять и пятнадцать кликов по имени в шапке — работает
только в русской версии: в остальных языках обработчик выключен.

## Локальный просмотр

Открыть `index.html` в браузере или поднять статический сервер:

```
python3 -m http.server 8000
```
